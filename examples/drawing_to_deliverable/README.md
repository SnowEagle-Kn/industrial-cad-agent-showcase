# Drawing DEMO media

These files are pre-generated DEMO/REPLAY illustrations for the drawing entry.
They are produced deterministically by `tools/build_demo_media.py` with the
Python standard library only.

- `deliverable-preview-2d.svg` — illustrative 2D plate view with DEMO watermark.
- `deliverable-preview-3d.png` — illustrative PNG preview; the tEXt metadata
  contains `DEMO / REPLAY`.

They do not measure the synthetic DXF and must not be used for manufacturing.
