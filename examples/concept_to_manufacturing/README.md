# Concept DEMO media

These files are pre-generated DEMO/REPLAY illustrations for the concept entry.
They are produced deterministically by `tools/build_demo_media.py` with the
Python standard library only.

- `concept-preview-2d.svg` — illustrative 2D concept view with DEMO watermark.
- `concept-preview-3d.png` — illustrative PNG preview; the tEXt metadata
  contains `DEMO / REPLAY`.

They are not dimensioned CAD output and must not be used for manufacturing.
