# Rights and sources registry

This registry preserves the source declarations of the original B3 local
candidate and identifies this release-closeout documentation revision. It
records provenance and source-display terms; it is not a standard open-source
license grant or a legal ownership determination.

Its per-file manifest and source register are retained outside the public
tree. The original register attributes the files to the
industrial-cad-agent-showcase authors (project owner), and records the
historical license-pending, internal-candidate authorization. It declares
original demo work or deterministic generation from that work, without copied
private-engine source, real project data or vendored third-party code.

These are baseline source declarations. The revised release tree needs an
updated per-file mapping and manifest; old hashes or approval do not describe
changed files automatically.

## Current source-display terms

- Current mode is `source-display-no-open-source-license`, following delegated
  decision `CAD-PUBLIC-CLOSEOUT-20261113-R0-r1`, D02, dated 2026-11-14.
- Source is intended for public capability display. All rights are reserved
  except as provided by law, applicable platform terms or another explicit
  agreement. GitHub public viewing and forking rights remain unaffected; this
  notice does not promise recall of existing copies or restrict platform rights.
- MIT and Apache-2.0 were historical candidates, not selections. No standard
  open-source license is granted. `LICENSE-PENDING.md` retains its historical
  filename and now states the current source-display terms.
- Original author attribution and source records are retained as declarations,
  not independent legal ownership findings. D02 is a delegated distribution-mode
  decision, not technical acceptance of the revised candidate.
- These terms concern only explicitly admitted public files. They grant no
  rights to an absent private engine, real project data or third-party material
  the project does not own. New or conflicting origin evidence remains unresolved
  for the affected object.

## Source isolation

The public tree must be assembled from an explicit file whitelist, not from
the private project root plus exclusions. The real CAD engine, complete rule
sets, full prompt text, private fixtures, real drawings, project logs, session
data, credentials and personal host paths remain outside it.

The original B3 review concerns a historical local candidate. It does not
authorize a changed release tree. The current rights mode derives from D02,
not from the historical B3 technical approval.
